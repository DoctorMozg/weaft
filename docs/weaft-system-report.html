🏗️ Architecture — Three-Crate Workspace

Dependency direction: weaft-cli → weaft-targets → weaft-core. Core has no internal deps.

weaft-core (library)

capability.rs — host capability matrix (the load-bearing artifact)
ir.rs — Project, Artifact, ArtifactMeta IR
parse.rs — disk → IR (flat + directory skill forms)
compile.rs — minijinja render w/ strict mode
kind.rs — closed 9-variant ArtifactKind
pipeline/ — resolve, map, emit stages
lint/ — 6 lint passes
tokens.rs, budget.rs, diag.rs, params.rs

weaft-targets (backends)

claude_code.rs — SKILL.md + agents/*.md
cursor.rs — .mdc rules + agents/*.md
agents_md.rs — merged AGENTS.md
opencode.rs — .opencode/skills & agents
codex.rs — Agent Skills std + TOML agents
gemini_cli.rs — all-Drop (unresearched)
serialize/ — YAML, TOML, JSON helpers

weaft-cli (binary)

commands/build.rs — compile_target, asset copy
commands/lint.rs — aggregate lint runner
commands/preview.rs — stdout render
commands/tokens.rs — token usage report

Used by: codex subagents (.codex/agents/{name}.toml). Rendered body goes into developer_instructions field.

Used by: agents-md, gemini-cli. Pure Markdown, no metadata block.

Key Field Rules (FieldSource)

TargetOverride("key")
Reads from targets.<host>.<key> in artifact frontmatter. Used for skill-level host-specific config: allowed_tools, model, globs, always_apply.
TopLevel("key")
Reads from a top-level frontmatter field. Used for structural fields (name, description) and subagent fields (tools, readonly, is_background).
Notable key casing rules
allowed_tools → emitted as allowed-tools (hyphen, Claude)
always_apply → emitted as alwaysApply (camelCase, Cursor)
Cursor Skill omits name key entirely

Disposition Types

Native
A real file is emitted at the path computed from the layout template. The artifact is fully supported by this host.
Fold { into: Kind }
This kind's content is merged into another kind's file. Currently used for Instruction→merged file (AGENTS.md, CLAUDE.md). Fold chains are forbidden: target must be Native.
Drop
The host cannot represent this kind. A warning is emitted instead of a file. Example: Subagent on agents-md.

📁 Skill Source Layouts (ADR-0007)

Two Accepted Forms

FLAT (original)
skills/safe-deleter.md
loader_root = project_root → fragments/ resolves from project root
DIRECTORY (ADR-0007)
skills/safe-deleter/SKILL.md
skills/safe-deleter/phases/research.md
skills/safe-deleter/phases/write.md
loader_root = skills/safe-deleter/ → includes resolve locally
Coexistence rule: if both forms exist for the same stem, directory wins. Flat is shadowed silently. duplicate_skill lint warning fires (error under --strict).

Fragment Pre-registration

All fragments/ files at project root are pre-registered as named templates at environment setup via add_template_owned(). Named templates resolve before the loader, so {% include "fragments/footer.md" %} works identically from both flat and directory skills.

# project/

flat-skill.md # include "fragments/footer.md.j2" ✓
dir-skill/
SKILL.md # include "fragments/footer.md.j2" ✓
phases/research.md # include "phases/research.md" ✓ (local)

🔍 Lint Passes

Run by weaft lint and automatically before weaft build. Pass --strict to escalate budget and layout warnings to errors.

required
lint/required.rs
Checks that every artifact has a name and description field. Hard error — never downgraded.
targets
lint/targets.rs
Checks for unknown target ids in targets.supported and artifacts that use unsupported host combinations (e.g. Subagent on agents-md).
layout
lint/layout.rs
Two passes: duplicate_skill (flat + directory coexistence) and missing_skill_md (skill directory with no SKILL.md).
⚠️ duplicate_skill: warn by default, hard error with --strict
missing_skill_md: always warn, never escalated
ask_user
lint/ask_user.rs
Validates use of AskUserQuestion / ask primitives against host support. Warns when a skill uses structured ask on a host that only supports non-blocking or no ask.
unused
lint/unused.rs
Checks for {{ params.* }} declarations that never appear in any artifact body. Helps catch stale parameter declarations.
⚠️ Known v1 limitation: for directory skills, only SKILL.md body is searched (not phase files). False-positives possible for params used only in phases.
budget
lint/budget.rs
Token/byte budget check. Renders each skill to count tokens (cl100k_base approximation). Hard byte budget: Codex AGENTS.md 32 KiB. Soft token budgets: claude-code 8000, cursor 6000.
⚠️ Budget overflow: warn by default, hard error with --strict
